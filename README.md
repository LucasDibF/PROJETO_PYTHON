# To-Do List — Django

Lista de tarefas simples feita em Django para o trabalho da disciplina de Paradigmas de Programação Python.

## Como rodar

```bash
python3 -m venv venv
source venv/bin/activate
pip install django
cd todolist
python manage.py migrate
python manage.py runserver
```

Abra [http://127.0.0.1:8000](http://127.0.0.1:8000) no navegador.
